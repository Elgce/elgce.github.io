统一的模型骨架

Attention 与 Transformer

Attention 不是“关注重要单词”的拟人化按钮，而是一种由内容动态决定信息混合权重的计算。

先记住一句话

每个位置用 Query 提问、用 Key 决定匹配程度，再按匹配权重汇总 Value；Transformer 把这种动态信息路由与逐位置非线性变换反复堆叠。

1. Transformer 要解决什么瓶颈？

RNN 按时间步递归更新状态。第 100 个 token 必须等待前 99 步，长距离信息也要反复穿过同一个状态通道。卷积可以并行，但要堆很多层或扩大 kernel 才能让远距离位置相互作用。

Self-attention 允许任意两个位置在一层内直接交换信息，而且训练时所有位置可以并行计算。原始 Transformer 论文在机器翻译中用 attention 完全替代 recurrence 和 convolution，这个计算骨架后来扩展到文字、图像、音频、视频和动作。

2. Q、K、V 分别是什么？

输入 hidden states 记为 $X\in\mathbb R^{n\times d}$。三个可学习线性映射产生：

$$Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V$$
  • Query：当前位置此刻想寻找什么信息。
  • Key：每个候选位置用什么特征接受匹配。
  • Value：匹配之后真正被搬运和混合的内容。

Q/K/V 都来自同一序列时叫 self-attention；Query 来自 decoder、Key/Value 来自 encoder 时叫 cross-attention。

3. 缩放点积注意力

一个 Query 与所有 Key 做点积得到相似度，除以 $\sqrt{d_k}$ 后经过 softmax，再加权求和 Value：

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V$$

$M$ 是可选 mask。为什么除以 $\sqrt{d_k}$？若各维近似独立、方差相近，点积方差会随维度 $d_k$ 增长。数值过大时 softmax 接近 one-hot，梯度容易变小；缩放让 logits 的典型尺度更稳定。

一个三位置的最小例子

假设某个 Query 与三个 Key 的缩放后分数是 $[2,1,0]$。softmax 大约得到 $[0.67,0.24,0.09]$。输出不是复制“最相关”的一个 Value，而是：

$$0.67V_1+0.24V_2+0.09V_3$$

因此 attention 本质是内容相关的加权信息混合。权重很大不自动等于“人类意义上的解释”或因果重要性。

4. Mask 到底遮住什么？

Mask 通常在 softmax 前把不允许的位置加上极大的负数（实现里常见 big_neg），使这些位置概率近似零。

Causal mask

位置 $t$ 不能看未来位置 $>t$。用于自回归语言模型，防止训练时偷看答案。

Padding mask

不同长度样本补齐后，禁止真实 token 关注没有内容的 padding 位置。

attention_mask 在不同代码库里可能表示布尔“允许矩阵”、0/1 有效位，或已加到 logits 的 bias。读代码时必须同时确认 shape、dtype、广播方向和 0/1 语义。

5. Multi-head 不是简单重复

每个 head 有自己的 $W_Q,W_K,W_V$，在较低维子空间中独立计算 attention。各 head 输出拼接后再线性投影：

$$\operatorname{MHA}(X)=\operatorname{Concat}(head_1,\ldots,head_h)W_O$$

不同 head 可以学习不同关系或不同位置模式，但没有保证某个 head 必然对应语法、指代等人类概念。多头的核心作用是提供多组独立的信息路由子空间。

6. 一个 Transformer block 还有什么？

x
 ├─ LayerNorm → Multi-Head Attention → + residual
 └─ LayerNorm → MLP / Feed-Forward    → + residual
  • Attention 在 token 之间混合信息。
  • MLP/FFN 对每个位置独立做非线性特征变换，通常先升维再降维。
  • Residual connection 保留原信息并改善深层优化。
  • LayerNorm 控制激活尺度；现代模型常使用 pre-norm。

7. 位置信息从哪里来？

纯 self-attention 若没有位置编码，对 token 排列的置换没有天然区分。原始 Transformer 加正弦位置编码；后续常见 learned position embedding、相对位置 bias 和 RoPE。RoPE 通过与位置有关的旋转作用于 Q/K，使点积自然携带相对位置信息。

8. 代价与边界

标准 attention 的 score matrix 是 $n\times n$，计算和显存随序列长度约为 $O(n^2)$。它能在一层建立长距离连接，但不是“无限上下文免费”：长序列仍受到显存、带宽、位置外推和有效利用能力限制。

常见误解：

Transformer 不等于 attention 一个公式。完整系统还包括 embedding、位置机制、MLP、残差、归一化、训练目标和大量系统优化。

自测

1. 为什么需要分别投影 Q、K、V？

匹配使用的特征与最终传递的内容可以不同；独立投影让模型学习“按什么匹配”和“匹配后传什么”。

2. 为什么 causal mask 要加在 softmax 前？

把禁止位置的 logit 变成极大负数后，它们的指数近似零，归一化概率也近似零；softmax 后再遮会破坏概率归一化。

3. Attention 与 MLP 在 block 中分别负责什么？

Attention 跨 token 路由和混合信息；MLP 对每个位置的通道特征做独立非线性变换。
