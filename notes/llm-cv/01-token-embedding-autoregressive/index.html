序列模型的地基

Token、Embedding 与自回归训练

模型怎样把原始信息变成数字，又怎样只靠“预测下一步”从海量无标签数据里学到结构。

先记住一句话

Token 决定模型处理的离散单位，embedding 把单位变成可学习向量，自回归目标则把一条序列变成许多“根据过去预测下一步”的监督题。

1. 为什么先要 tokenization？

神经网络只接收固定形状的数字张量，不能直接计算字符串、图片或机器人动作。第一步因此不是“理解”，而是把原始对象表示成一串有限词表中的离散单元。

"I love robotics"
        ↓ tokenizer（仅为示意）
["I", " love", " robot", "ics"]
        ↓ vocabulary lookup
[40, 1842, 9201, 1127]

token 不等于单词。它可以是字符、子词、字节、图像 patch、视觉 code，或者离散动作。Tokenizer 做的是一种工程折中：

  • 词表很大：常见词可能只占一个 token，但 embedding/output 层更大，稀有词也难覆盖。
  • 词表很小：几乎不会遇到未知词，但每段文本会变长，attention 和生成成本随之上升。
  • 子词或字节：在覆盖率、序列长度和多语言能力之间折中，因此成为常见方案。
不要误读 token ID：

ID 只是类别编号。编号 100 不比编号 10 “大十倍”，两个 ID 数字接近也不代表语义接近。

2. Embedding：把类别变成坐标

设词表大小为 $V$、模型宽度为 $d$。模型维护一个可训练矩阵 $E\in\mathbb{R}^{V\times d}$。token $i$ 的输入向量就是第 $i$ 行：

$$\mathbf e_i = E[i]$$

这等价于 one-hot 向量乘以矩阵，却不用真的构造巨大 one-hot。训练开始时这些向量通常接近随机；为了降低预测损失，梯度会同时更新 embedding 和网络其他参数。

要区分两种经常都被叫作“表示”的东西：

输入 embedding

只由 token ID 查表得到。同一个 token 每次进入模型时起点相同。

上下文 hidden state

经过多层 attention 后形成。同一个 token 在不同句子中可以完全不同。

所以“embedding 是词义”只是粗略直觉。真正参与下一 token 预测的是当前位置的上下文 hidden state。

3. 自回归到底是什么意思？

自回归不是某个网络结构，而是一种概率分解。概率链式法则给出：

$$p(x_{1:T})=\prod_{t=1}^{T}p(x_t\mid x_{<t})$$

模型只需要学会每一步的条件分布 $p(x_t\mid x_{<t})$，这些分布相乘便定义了整个序列的概率。RNN、Transformer 或其他网络都可以参数化它。

例如序列 I love robotics <EOS> 会产生多道训练题：

看到：<BOS>                 → 预测：I
看到：<BOS> I               → 预测：love
看到：<BOS> I love          → 预测：robotics
看到：<BOS> I love robotics → 预测：<EOS>

这就是 next-token prediction。它的监督标签直接来自原始序列本身，因此不需要人工逐条标注任务答案，通常被称为自监督学习。

4. Teacher forcing、causal mask 与 loss

训练时整条正确序列已经存在。我们把真实的历史 token 提供给每个位置，这叫 teacher forcing。Transformer 再用 causal mask 禁止位置 $t$ 看见未来 $t+1:T$，便可以一次前向并行计算所有预测题。

每个位置输出整个词表上的 logits。softmax 把它变成概率，正确 token 的交叉熵为：

$$\mathcal L_t=-\log p_\theta(x_t\mid x_{<t})$$

对所有有效位置求和或平均，就是 sequence loss。最小化它等价于最大化训练序列在模型下的 likelihood：模型不断提高真实后续的概率。

训练

正确历史全部已知；各位置可并行预测；早期错误不会改写本样本后面的输入。

生成

下一 token 尚不存在；必须把自己的输出接回输入；前面的错误会改变后续条件。

训练和自由生成条件不完全相同，常被称为 exposure bias 或 train–inference mismatch。但这不代表 teacher forcing 是错误方法；它让大规模训练高效而稳定，代价是推理时必须处理自身输出造成的分布偏移。

5. 为什么一个简单目标会学到很多能力？

要准确预测文本后续，模型经常必须利用语法、语义、事实、篇章结构和任务格式。数据规模扩大后，不同能力共享一套表示和参数，于是 next-token objective 成为一个通用训练接口。

但它不保证模型学到“真实世界的正确因果模型”。训练目标只要求拟合数据分布：数据里的偏见、错误和表面捷径也会被学习。指令遵循、事实可靠性和安全性通常还需要后训练或外部工具。

6. 放到机器人动作模型里

如果观测 $o$ 包含图像、语言指令和本体状态，动作序列也可以自回归分解：

$$p(a_{1:T}\mid o)=\prod_{t=1}^{T}p(a_t\mid o,a_{<t})$$

与文本相同的是“过去条件下预测下一步”；不同的是动作可能是连续值，而且控制系统要求低延迟、平滑、闭环纠错。因此机器人模型可能预测离散 action token，也可能生成连续 action chunk，或者使用 diffusion / flow matching 并行产生一段动作。

重要边界：

自回归描述的是概率分解和生成顺序，不等于语言，不等于离散输出，也不等于 Transformer。

自测

1. 为什么不能把 token ID 当作有大小关系的连续数值？

它只是类别编号；数值距离不携带语义。Embedding lookup 为每个类别提供独立的可学习向量。

2. 自回归训练为什么能并行，推理通常为什么不能？

训练时正确序列完整可见，causal mask 能让所有位置同时预测下一 token；推理时第 $t+1$ 步输入依赖第 $t$ 步刚生成的结果。

3. Cross-entropy 与 maximum likelihood 的关系是什么？

逐 token 的交叉熵是正确 token 条件概率的负对数；求和即序列的负 log-likelihood，所以最小化前者等价于最大化后者。
